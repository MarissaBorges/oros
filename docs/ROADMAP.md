# OROS expansion roadmap

## Near term

- Vision model adapter for real-time screen understanding.
- Persistent approval queue with audit records.
- Browser session registry for Chrome, Firefox, and Zen.
- Vault backlinks, templates, Dataview-compatible summaries, and daily notes.
- Google OAuth setup UI and connector health checks.
- Project profiles for build, test, lint, and run commands.
- Deep-research reports exported to the vault.
- Desktop notifications and optional speech output.

## Autonomous operations

- Daily morning digest from calendar, email, tasks, health, news, and the vault.
- Continuous project monitor that watches Git, tests, CI, logs, and issues.
- Autonomous bug triage with branch, reproducer, patch, tests, and PR draft.
- Research digest that follows topics and opens new evidence in the browser.
- Meeting preparation that gathers calendar context and relevant vault notes.
- Inbox classification and draft responses with a review queue.
- Dependency and security drift monitoring with upgrade plans.

## Long term

- Multi-agent workspaces with role-specific policies.
- Provenance graph linking facts, sources, notes, and actions.
- Local personal knowledge index with semantic retrieval.
- Energy-aware model routing across Ollama and selected cloud engines.
- Persistent memory with forgetting, redaction, and retention policies.
- MCP integrations for external developer and business tools.
- Optional Android/Apple channel gateways.
- A visual action recorder that converts repeated workflows into skills.
